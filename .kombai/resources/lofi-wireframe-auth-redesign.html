Auth Page Wireframe — Facebook-Inspired Centered Card

Redesign inspired by Facebook/Meta's clean, centered auth approach: social auth first, clear tab navigation between sign-in and sign-up, floating-label inputs, password visibility toggle, strength indicator, and a prominent terms link. Removes the decorative split-panel in favor of a focused, conversion-optimized single-column layout.

[REUSE] Existing component in codebase [NEW] New component to create
Key differences from current design:
  1. Centered card replaces split-screen layout → works identically on all screen sizes
  2. Sign In / Sign Up as tabs at top of card → no page-level state jump
  3. Social auth buttons elevated above email/password form → matches Facebook's hierarchy
  4. FloatingLabelInput replaces plain inputs → more accessible, more compact
  5. Password visibility toggle + strength indicator added to Sign Up
  6. Forgot password as dedicated link with proper affordance
  7. Terms of Service as actual anchor link, not plain text
  8. Social proof moved above card as trust signal (not buried in decorative panel)
